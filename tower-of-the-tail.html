What I did

A desktop platformer-strategy game for macOS and Windows: players climb a dangerous tower as Klutz, an adventurous mouse, while managing a power-filled inventory. Made by the student team Defund Gravity.

  • Designed end-to-end UI/UX for a desktop platformer-strategy game, creating HUD layouts and in-game menu systems for the core gameplay screens.
  • Designed onboarding flows and tutorial UI for new players, easing the learning curve for inventory, combat, and power-management game mechanics.
  • Crafted the player character Klutz and enemy visual assets, establishing a cohesive visual design system that balances readability with game mood.
  • Iterated on inventory and power-management UI through playtesting feedback, improving player comprehension of item interactions and hazard cues.
  • Collaborated with programming and design leads in an Agile team of 9, translating design documents into production-ready assets for two builds.
